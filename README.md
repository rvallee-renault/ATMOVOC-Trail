# ATMOVOC TRAIL

Application terrain (smartphone) d'investigation COV, compagnon d'ATMOVOC PC (V3.0.28 et suivantes).

- Aucune donnée réelle dans ce dépôt : la démo utilise un site fictif aux chiffres inventés.
- Les packs d'enquête et comptes rendus de visite restent sur le téléphone / OneDrive ; rien n'est envoyé sur Internet.
- Fonctionne hors connexion après la première ouverture.

Fichiers : `index.html` (application), `manifest.webmanifest`, `sw.js` (hors connexion), `icon-*.png`.
